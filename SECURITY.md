# Security Policy

## Supported versions

This is a private project; only the latest `main` branch is maintained.

## Reporting a vulnerability

Do not open a public issue. Report vulnerabilities privately using GitHub's
"Report a vulnerability" flow (Security > Advisories) on this repository, or
contact the maintainer directly.

Please include:

- a description of the issue and its impact
- reproduction steps or a proof of concept
- the affected versions or commits

We aim to acknowledge reports within a few days.
